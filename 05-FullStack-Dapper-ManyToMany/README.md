# 05. Full-Stack Blazor з базою даних (Dapper та зв'язки Many-to-Many)

> **Технології**: .NET 10, Blazor Server, Dapper ORM, Microsoft SQL Server, Many-to-Many (M:N), Stored Procedures.

---

## 📌 Огляд модуля
Повноцінний практичний Full-Stack застосунок на Blazor Server з прямим підключенням до реляційної СУБД:

1. **Архітектура доступу до даних**:
   - Використання мікро-ORM **Dapper** для виконання швидких SQL-запитів та збережених процедур.
   - Зв'язки «багато-до-багатьох» (M:N) між сутностями (наприклад, Книги та Автори / Студенти та Курси) через проміжну таблицю зв'язку.
2. **Інтерактивний Blazor UI**:
   - Перегляд зв'язаних списків даних у реальному часі.
   - Форми додавання, редагування та видалення записів з одночасним оновленням проміжних ключів зв'язку.
3. **База даних**:
   - Файл `database_sql.sql` містить повну схему таблиць, індексів та тестові дані.

---

## 🚀 Як розгорнути та запустити
1. Відкрийте `database_sql.sql` у SQL Server Management Studio (SSMS) або Azure Data Studio та виконайте його.
2. Перевірте рядок підключення у `appsettings.json` (за замовчуванням LocalDB / SQL Server Express).
3. Запустіть проєкт:
   ```bash
   cd Blazor_manyTomany_Dapper
   dotnet run
   ```
