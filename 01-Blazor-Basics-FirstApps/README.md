# 01. Основи Blazor: Перші застосунки та Маршрутизація

> **Технології**: .NET 10, Blazor Server, Razor Components, Routing, Navigation.

---

## 📌 Огляд модуля
Модуль присвячений основам створення односторінкових веб-застосунків на базі Blazor Server:
1. **`BlazorFirstApp`**: Базовий шаблон застосунку, знайомство з структурою сторінок (`Pages/`), спільними компонентами (`Shared/`), та точкою входу (`Program.cs`).
2. **`Example_BlazorFirstApp_02`**: Організація компонентів, маршрутизація через директиву `@page`, навігація за допомогою `NavLink` та `NavigationManager`.

---

## 🔑 Ключові концепції
- **Razor синтаксис**: поєднання розмітки HTML та коду C# у файлах `.razor`.
- **Маршрутизація (`@page "/path"`)**: прив'язка компонентів до конкретних URL-шляхів.
- **Дерево компонентів**: передача параметрів між батьківськими та дочірніми елементами.
- **Спільні макети (`MainLayout.razor`)**: визначення каркаса сайту (шапка, меню, контентна область).

---

## 🚀 Запуск
```bash
cd BlazorFirstApp
dotnet run
```
